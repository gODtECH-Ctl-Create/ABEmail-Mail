# Waste2Light ABEmail Operations Roadmap

1. Finish security hardening and manual provider security settings.
2. Validate Search, Mark All as Read, Reply/Forward, Attachments and Drafts before merging.
3. Harden and test Web Push.
4. Implement structured event logging and correlation IDs.
5. Implement automatic incident detection and the ABE Tech Lab admin dashboard.
6. Add user-facing issue reporting linked to incidents.
7. Add critical incident notifications for ABE Tech Lab.
8. Add retention/privacy/audit controls.

The Admin console is for ABE Tech Lab operations. Waste2Light users use the normal mail application.
